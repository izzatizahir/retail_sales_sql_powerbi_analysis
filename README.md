# Retail Sales SQL & Power BI Analysis

## Project Overview

This project analyzes retail sales transaction data using SQL and Power BI to uncover sales trends, customer behavior, and product performance.

## Tools Used

- Microsoft Excel
- SQL (SQLite)
- Power BI
- GitHub

## SQL Analysis

The following business questions were answered:

1. Total Revenue
2. Revenue by Product Category
3. Revenue by Gender
4. Top 10 Customers by Revenue
5. Monthly Sales Trend
6. Revenue by Age Group
7. Best Selling Product Category

## Dashboard KPIs

- Total Revenue
- Total Transactions
- Average Order Value

## Dashboard Visuals

- Revenue by Product Category
- Revenue by Gender
- Monthly Sales Trend
- Revenue by Age Group
- Top 10 Customers
- Interactive Slicers

## Key Insights

- Electronics generated the highest revenue.
- Male and Female customers contributed almost equally to total revenue.
- The 25-54 age group contributed the majority of sales.
- Customer spending patterns can be identified through the Top 10 Customers analysis.
